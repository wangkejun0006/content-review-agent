# 独立发布候选验证范围

本候选在独立目录整理，不修改原应用仓库和已有脱敏副本，不迁入作者的数据库、凭据、旧活动额度或node_modules/虚拟环境。首次安装允许访问依赖包仓库；运行测试与演示不调用模型。

验收分为：新虚拟环境与锁文件安装、前端安装/测试/构建、便携后端回归、临时SQLite复杂资料排练、新PostgreSQL与Volume初始化、四个新Worker进程的HTTP闭环、页面创建任务至返工审核和虚构登记/反馈，以及停止/重启后保留审核状态。

所有报告和失败尝试写入全新路径，历史报告不重跑覆盖。最终精确结果见随候选提供的 release 验证摘要；本说明本身不预先断言全部检查成功。

自动化角色审核不是实际真人决策；模拟记录不是外部发布；确定性正文和内部评分不是模型质量或业务效果证据。未验证生产部署、多主机并发、真实用户和平台政策准确性。共享Docker Engine、uv/npm包缓存和浏览器缓存不等于复制旧运行环境，验收报告须说明这些共享项。

仍有前端bundle超过500kB的非阻断警告。Linux/WSL主机、Docker Engine、包缓存和浏览器安装共享；不声称在全新操作系统、Windows原生Python或生产服务器通过验收。数据库镜像标签当前未固定到digest，摘要记录本轮实际使用的digest。
